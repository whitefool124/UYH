# Day 4 教学关结构搭建

## 1. 目标

Day 4 的目标不是把第一关完整做完，而是把“教学关”从抽象概念落成可开发的结构方案。

本日需要明确四件事：

1. 教学关场景骨架
2. 识别、移动、施法教学步骤
3. 低压敌人遭遇配置
4. 出口 / 完成节点

## 2. 教学关场景骨架

### 2.1 场景定位

教学关是玩家进入试炼空间后的第一段正式交互区域，它的主要职责是：

- 让玩家在无额外说明的情况下理解“我可以完全用手势操作这个游戏”
- 在低风险下依次学习 UI、移动、施法、推进
- 用最短路径走完一个完整闭环

### 2.2 推荐空间结构

建议采用线性短流程结构：

1. 起始唤醒区
2. UI / 进入确认区
3. 基础移动试炼区
4. 基础施法试炼区
5. 低压战斗区
6. 出口节点区

### 2.3 空间组成建议

#### A 区：唤醒与观察区

- 功能：玩家进入场景后先稳定观察
- 内容：低压、无敌人、可看到前方出口方向或能量门
- 目的：让玩家先理解视角和环境，不立刻进入战斗压力

#### B 区：纯手势 UI 交互区

- 功能：完成一次开始 / 继续 / 模式确认
- 内容：一个纯手势 UI 面板或短链路交互界面
- 目的：兑现 P0 中“至少一个完全由手势驱动的 UI 交互界面”

#### C 区：基础移动区

- 功能：练习前后左右固定距离移动、锁定切换与辅助视角配合
- 内容：若干明显的地面格 / 节点 / 目标格
- 目的：让玩家理解“这是离散推进，不是摇杆走路”

#### D 区：基础施法区

- 功能：练习火 / 冰 / 盾三法术
- 内容：静止或低压目标、简单法阵、明确提示板
- 目的：让玩家理解每种法术至少一个用途

#### E 区：低压战斗区

- 功能：第一次推进式遭遇战
- 内容：少量追击敌 + 少量冲刺敌提醒
- 目的：让玩家把移动和施法第一次组合起来

#### F 区：出口节点区

- 功能：完成关卡收尾
- 内容：出口门、法阵或节点激活装置
- 目的：形成“推进 -> 清场 -> 到达出口”的闭环认知

## 3. 教学步骤设计

### Step 1：观察与接入

- 玩家醒来 / 进入场景
- 老师或系统给出一句极短提示
- 玩家先理解空间锚点和目标方向

### Step 2：纯手势 UI 界面演示

- 用左右切换 + 确认完成一次纯手势 UI 操作
- 玩家进入下一教学段

### Step 3：基础移动教学

- 让玩家完成四向离散位移中的最基础动作
- 至少需要完成一次前进和一次横向换位

### Step 4：基础法术教学

- 火焰术：清除单一目标
- 冰霜术：处理需要被按住节奏的目标
- 护盾术：在危险提示下顶住一次压力

### Step 5：低压推进式遭遇战

- 让玩家在少量敌人压力下前进
- 需要至少一次移动和至少两种法术配合

### Step 6：出口节点激活

- 敌人清掉后到达出口
- 通过关卡完成节点触发胜利推进

## 4. 低压敌人遭遇配置

### 4.1 设计原则

- 敌人只承担教学作用，不承担高压挑战作用
- 重点是让玩家理解“为什么我需要动”和“为什么不同法术有区别”

### 4.2 推荐配置

#### 第一小波

- 2 个追击敌
- 目的：教学火焰术点杀和最基础前进

#### 第二小波

- 3 个追击敌
- 目的：教学冰霜术控场价值

#### 第三小波

- 2 个追击敌 + 1 个冲刺敌
- 目的：教学“不要站着不动”和护盾 / 换位反应

### 4.3 不建议出现的内容

- 压制敌
- 护甲敌
- 多重危险区叠加
- 双路线选择

这些内容应留到后续关卡再引入。

## 5. 出口 / 完成节点设计

### 5.1 推荐形式

- 一个明显的全息门
- 或一个出口法阵
- 或一个需要激活的终端节点

### 5.2 功能要求

- 敌人清空后才能激活
- 激活方式必须依旧支持纯手势完成
- 激活后要有明确视觉反馈，告诉玩家本段试炼已结束

### 5.3 玩家感受目标

- 我不是打了一波怪就结束了
- 我是“通过了一段试炼，并进入下一段”

## 6. Day 4 结论

- 教学关应采用短线性推进结构，不做开放探索。
- 教学顺序必须是：UI -> 移动 -> 施法 -> 低压战斗 -> 出口闭环。
- 敌人配置应以追击敌为主，只用极少量冲刺敌提醒“不要站桩”。
- 出口节点必须成为教学关收尾的一部分，而不是战斗结束后自动跳转。
- 如果手势输入实现尚未完全稳定，教学关允许先用键鼠映射做临时流程验证。
