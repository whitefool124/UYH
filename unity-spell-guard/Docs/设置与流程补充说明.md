# 符印守卫 设置与流程补充说明

## 1. 当前目标

在关卡设计、法术实现、手势识别之外，设置、UI 流程和基础属性需要达到“可支撑完整演示闭环”的状态。

## 2. 设置系统当前能力

当前设置页已经支持：

- 施法确认时长切换
- 敌人节奏切换
- 返回主菜单

设置系统当前通过 `SpellGuardGameSettings` 统一管理，并由流程页和 HUD 消费。

## 3. 流程页当前能力

当前流程页和状态包括：

- 主菜单
- 设置
- 教程
- 训练
- 战斗
- 结果页

这些流程已具备：

- 焦点切换
- 确认触发
- 返回逻辑
- 基础状态反馈

## 4. 属性与计算层当前能力

当前属性与计算已开始从硬编码收束为：

- `SpellConfig`
- `SpellConfigLibrary`
- `EnemyConfig`
- `DifficultySettings`

其作用是把：

- 法术效果参数
- 敌人基础参数
- 难度参数

统一到更清晰的配置入口中。

## 5. 当前结论

- 非核心系统已经足以支撑答辩版闭环。
- 后续内容开发可以建立在当前设置、UI 流程和属性层之上继续推进。
