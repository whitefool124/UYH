# 符印守卫 美术风格规范：全息试炼空间

## 1. 风格总述

整体风格采用“全息试炼空间”方向：玩家并非在传统神殿或自然场景中施法，而是在一个由未来技术驱动的试炼环境中，通过手势激活全息术式、能量结界与战斗模块。

核心关键词：

- 未来感
- 全息投影
- 能量结界
- 几何符印
- 训练场 / 试炼空间
- 冷色调高对比
- 低复杂度高识别度

## 2. 场景风格规范

### 2.1 场景气质

- 场景应表现为“未来技术生成的试炼空间”，而不是传统自然地貌或古典奇幻神殿。
- 空间结构以几何、模块化、规则化为主，强调人工构造感和系统控制感。
- 整体氛围偏冷静、克制、理性，让玩家感到自己是在进入一个用于测试施法与战斗能力的高科技环境。

### 2.2 结构语言

- 大面积使用规则几何形体：方形平台、环形区域、切角门框、悬浮边界、分层地台。
- 地图边界建议通过能量墙、全息屏障、光栅边框表达，而非厚重实体墙体。
- 地面可分为：安全区、战斗区、危险区、目标区，通过不同发光纹路和材质变化区分。

### 2.3 颜色系统

- 主基调：深蓝黑、冷灰、深炭灰。
- 辅助高亮：青蓝、冷白、电紫。
- 危险提示：橙红或亮红。
- 地图整体应保持暗背景，交互与反馈区域高亮发光，形成清晰层次。

### 2.4 可读性要求

- 地图必须优先服务战斗与交互识别，不应堆积过多无功能细节。
- 所有可交互区域都应有明显的轮廓、边缘光或动态线框提示。
- 敌人、目标、危险区必须能在第一眼与背景区分开。

## 3. UI 风格规范

### 3.1 基础方向

- UI 采用全息终端 / 战斗投影风格，不使用传统卷轴、木框、羊皮纸等古典元素。
- 所有 UI 面板应给人一种“战斗系统界面”或“试炼控制台”的感觉。

### 3.2 面板表现

- 使用半透明深色底板 + 发光描边。
- 边框宜采用细线框、切角、能量边缘、扫描线效果。
- 状态切换和聚焦应依赖光效变化，而不是厚重立体按钮。

### 3.3 按钮与选择反馈

- 手势停留选择时，按钮应有充能式进度反馈。
- 焦点高亮建议采用外轮廓发光、色彩增亮、进度填充而不是位移跳动。
- 完全手势驱动的 UI 交互界面必须做到：远看清楚，近看有层次，误识别时反馈明确。

### 3.4 HUD 规范

- HUD 以低干扰、高信息密度为原则。
- 生命、护盾、敌人数、当前手势、动态动作状态都应有简洁而稳定的显示位置。
- 不建议使用过多拟物组件，尽量以发光文字、图标、能量条表达。

## 4. 法术特效规范

### 4.1 总原则

- 法术不是传统奇幻“自然魔法”，而是由手势激活的未来术式或能量协议。
- 特效视觉应强调“能量启动、系统响应、几何展开、目标命中”的科技感。

### 4.2 火焰术

- 视觉方向：高能热能脉冲 / 橙红色离子冲击。
- 应表现为快速、直接、强冲击的输出型术式。
- 允许使用细碎粒子、热能尾迹、短时爆闪。

### 4.3 冰霜术

- 视觉方向：低温冻结场 / 蓝白色晶格束缚。
- 应表现为控场、减速、冻结，不是普通雪球。
- 推荐加入晶格展开、六边形冻结纹理、低温波纹。

### 4.4 护盾术

- 视觉方向：球面能量盾 / 六边形折射屏障。
- 应清楚表现“展开、维持、破裂”三个状态。
- 护盾不宜过厚重，应更像未来能量层而不是实体金属板。

### 4.5 动态手势高光反馈

- Snap、Swipe、双手动作等高阶输入应有单独高光反馈。
- 触发时可出现空中轨迹线、投影符号、能量脉冲环、系统锁定提示。
- 动态动作的反馈要比静态姿势更短、更亮、更有爆发感。

## 5. 敌人风格规范

### 5.1 轮廓要求

- 敌人应优先保证轮廓清晰，避免过多细碎结构。
- 即使在低光环境下，也必须能通过轮廓和发光部位快速辨识威胁类型。

### 5.2 视觉分层

- 普通敌：低亮度、低复杂度，作为基础威胁。
- 高压敌：更强发光核心、更明显危险色。
- 冲刺敌：轮廓更尖锐、姿态更前倾、速度反馈更明显。
- 远程 / 压制敌：应有清晰的蓄力与攻击提示。

### 5.3 世界观统一性

- 敌人应看起来像试炼系统生成的战斗体、守卫体、异常体，而不是完全写实生物。
- 允许使用半机械、能量包裹、全息碎片、几何断片等视觉元素。

## 6. 推荐落地方向

- 答辩版优先做：场景基调、基础 UI、三法术特效的统一未来风包装。
- 比赛版再强化：敌人分层、危险区视觉、动态动作高光和高级演示包装。
