# 符印守卫 美术资产需求表

## 1. 使用说明

- 本表用于拆分答辩版与比赛版所需的美术资产。
- 优先级分为：P0 / P1 / P2。
- `现状` 用于标记当前是否已有临时原型替代。
- 本表默认以“全息试炼空间”作为统一风格方向。

## 7. 推荐制作顺序

### 第一优先级（答辩闭环）

- 教学关主场景骨架
- 开始界面 / 模式说明 / 结算页基础视觉
- 三种基础法术特效
- 普通敌基础外观
- 场景焦点物：祭坛 / 出口 / 法阵

### 第二优先级（游戏感提升）

- 第二关场景骨架
- 敌人差异化外观
- 命中 / 受击 / 护盾反馈
- 动态手势高亮反馈
- 手势提示图标与目标提示框

### 第三优先级（比赛强化）

- 第三关高潮场景
- Boss / 高压敌视觉
- 更完整的封面、截图、演示包装素材

## 8. 当前结论

- P0 资产重点是“闭环可演示”，不是追求完整高精度美术。
- P1 资产重点是“玩法差异和反馈强化”。
- P2 资产重点是“高潮表现和比赛包装”。
