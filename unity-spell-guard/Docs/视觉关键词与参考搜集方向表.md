- 本表用于后续搜集参考图、视频和材质方向。
- 每一项关键词都应服务于“全息试炼空间”这一总方向。
- 建议把搜到的参考按“场景 / UI / 法术 / 敌人 / 演示包装”分类存档。

## 6. 参考搜集重点

### 场景参考重点

- 看空间是否开阔、是否利于战斗可读性
- 看地面和边界如何区分功能区域
- 看中心锚点是否足够强

### UI 参考重点

- 看按钮停留选择反馈
- 看高亮和发光边框是否清楚
- 看未来感与信息可读性是否平衡

### 法术参考重点

- 看三类法术是否在颜色、形态、节奏上明显不同
- 看动态动作触发时是否有更强高光反馈

### 敌人参考重点

- 看轮廓是否清楚
- 看不同敌人类型是否一眼可区分
- 看发光核心和危险色的使用方式

## 7. 参考筛选原则

- 优先选择暗背景 + 高亮反馈明确的参考
- 优先选择几何感、全息感强的素材
- 不选过于写实、过于繁杂、难以低成本复现的方向
- 不选完全偏赛博城市街景的方向，应保持“试炼空间”特征
