# Spell Guard UI Sprites

Production UI assets for Unity import.

Style target: ultra minimal, elegant, calm futuristic gateway UI. Keep the interface spacious, restrained, architectural, and premium. Avoid busy glow, dense decoration, fantasy ornament, web-dashboard styling, or mobile-app styling.

## Files

- `ui_panel_large.png` - main menu / settings / results large panel
- `ui_panel_small.png` - small card / tooltip / subpanel
- `ui_button_primary.png` - primary action button
- `ui_button_secondary.png` - secondary action button
- `ui_progress_bar.png` - confirmation / loading / dwell bar
- `ui_hud_frame.png` - HUD container frame
- `ui_icon_energy.png` - energy / spell power icon
- `ui_icon_shield.png` - shield icon
- `ui_icon_spell.png` - spell glyph icon
- `ui_divider.png` - separator line

## Unity import suggestion

- Texture Type: Sprite (2D and UI)
- Sprite Mode: Single
- Mesh Type: Full Rect
- Generate Mip Maps: Off
- Alpha Is Transparency: On
- Wrap Mode: Clamp

Use `ui_panel_large` and `ui_panel_small` as 9-slice sources if needed.
