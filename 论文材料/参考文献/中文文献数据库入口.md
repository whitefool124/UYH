# 中文文献数据库入口

建议优先通过学校图书馆的“电子资源 / 数据库导航 / 校外访问 / CARSI”进入。直接打开数据库官网有时不能识别学校权限，可能只能看到摘要或需要个人付费。

## 核心中文数据库

| 平台 | 入口 | 适合找什么 | 使用建议 |
|---|---|---|---|
| 中国知网 CNKI | https://www.cnki.net/ | 中文期刊、硕博论文、会议论文，最适合找中文毕业论文相关背景。 | 通过学校图书馆入口或知网“机构登录 / 校外访问”进入。 |
| 万方数据 | https://www.wanfangdata.com.cn/ | 中文期刊、学位论文、会议、标准，适合作为知网补充。 | 用题名检索，常能找到知网没有权限的替代全文。 |
| 维普中文期刊服务平台 | https://www.cqvip.com/ | 中文期刊，适合补中文综述、应用类论文。 | 对“手势识别”“体感游戏”“人机交互”等中文关键词较友好。 |
| 国家科技图书文献中心 NSTL | https://www.nstl.gov.cn/ | 科技文献、外文资源检索、文献传递。 | 适合查外文论文元数据和可能的全文入口。 |
| 国家哲学社会科学文献中心 | https://www.ncpssd.org/ 或 https://www.ncpssd.cn/ | 社科、人机交互、教育、体育、康复类中文文献。 | 免费资源较多，可补“体感游戏应用价值”背景。 |
| 读秀学术搜索 | https://www.duxiu.com/ | 图书、学位论文、期刊线索。 | 常通过学校购买，适合找书籍章节和中文论文线索。 |
| 超星发现 | https://www.chaoxing.com/ | 图书、期刊、学位论文聚合检索。 | 通常走学校入口；可用于扩大检索。 |
| 百度学术 | https://xueshu.baidu.com/ | 中文题名检索、跳转不同数据库。 | 适合作为入口，不一定直接下载全文。 |
| Google Scholar | https://scholar.google.com/ | 外文论文入口、PDF 侧栏。 | 用英文题名 + `PDF` 检索，和学校数据库配合。 |

### 校外访问方式

浙工大图书馆说明校外访问主要有两种：

1. 工大 VPN；
2. CARSI 统一身份认证，推荐路径是进入 CARSI 登录页，选择“浙江工业大学”，再使用学校统一身份认证登录。

CARSI 入口：https://ds.carsi.edu.cn/login/index.html

如果你已经在校园网或 VPN 内，优先直接从数据库页面进入；如果在校外，优先按图书馆页面的 CARSI 方式进入。

## 中文关键词

围绕你的论文主题，建议在知网、万方、维普中使用以下组合：

| 方向 | 检索词 |
|---|---|
| 手势识别基础 | `手势识别 人机交互`、`视觉手势识别 综述`、`动态手势识别 关键点` |
| MediaPipe | `MediaPipe 手势识别`、`MediaPipe Hands 手部关键点`、`MediaPipe 人机交互` |
| 动态手势 | `动态手势识别 轨迹`、`动态手势 时间序列`、`手势轨迹识别` |
| 体感游戏 | `体感游戏 手势交互`、`体感交互 游戏 Unity`、`手势控制 游戏` |
| Unity 实现 | `Unity 手势识别`、`Unity 体感交互`、`Unity 人机交互 手势` |
| 康复/训练应用 | `体感游戏 康复训练`、`体感交互 教育`、`动作识别 康复游戏` |
| 深度学习对比 | `手势识别 LSTM`、`手势识别 Transformer`、`骨架序列 手势识别` |

## 下载策略

1. 先用中文关键词在 CNKI 找综述和硕博论文，确定中文表述。
2. 同一题名在万方、维普再搜一次，遇到知网无权限时可能有替代全文。
3. 学位论文只选 2-3 篇做背景参考，不要让参考文献列表被硕博论文占满。
4. 中文文献主要支撑第 1 章和第 2 章，方法和核心技术仍以英文论文为主。
5. 下载后统一放入 `论文材料/参考文献/`，文件名建议格式：`CN_作者_主题_年份.pdf`。

## 最值得补的中文文献类型

- 1-2 篇 `视觉手势识别综述`。
- 1-2 篇 `MediaPipe 手势识别应用`。
- 1-2 篇 `Unity / 体感游戏 / 手势交互`。
- 1 篇 `体感游戏在康复、教育或训练中的应用`。

有这些中文文献后，第 1 章和第 2 章会更像国内本科毕设论文；外文文献则继续支撑算法和技术路线。
