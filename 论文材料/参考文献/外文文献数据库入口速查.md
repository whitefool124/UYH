## 2. 优先下载平台

| 平台 | 优先级 | 适合补什么 |
|---|---|---|
| Springer | 高 | Hand gesture recognition、MediaPipe、HCI、computer vision 综述和应用论文 |
| ScienceDirect | 高 | Computer vision、human activity recognition、HCI、game interaction 方向期刊 |
| ACM Digital Library | 中高 | CHI、UIST、game interaction、human-computer interaction 会议论文 |
| IEEE Xplore | 中高 | Gesture recognition、real-time recognition、vision-based interaction |
| Wiley / Taylor / Emerald | 中 | 作为补充检索，优先级低于前三者 |

## 5. 下载后的命名规则

目录：

`E:\bishe\gesture-game\论文材料\参考文献`

建议命名：

`EN_作者_主题_年份.pdf`

示例：

- `EN_Zhang_DynamicHandGestureTransformer_2024.pdf`
- `EN_Smith_MediaPipeHandGestureRecognition_2023.pdf`
- `EN_Brown_GestureInteractionGame_2022.pdf`

## 6. 操作路线

1. 先进入 Springer 或 ScienceDirect。
2. 搜 `"MediaPipe" "hand gesture recognition"`。
3. 年份筛 2021-2026，优先下载 2023-2026。
4. 下载 PDF，不下载只有摘要、没有全文权限的页面。
5. 遇到无权限论文，记录到 `待下载文献清单.md`，不要在上面浪费时间。
6. 每篇下载后检查文件大小，正常论文通常大于 200 KB；几十 KB 的文件可能只是网页壳或错误页。
